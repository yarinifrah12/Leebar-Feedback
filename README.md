# מערכת משוב חדר אוכל – LEE BAR

שני דפים נפרדים והגיליון שלך:

| מה | קובץ | למי |
|---|---|---|
| סקר לטאבלט | `indexF.html` | הטאבלט בכניסה. אפשר רק למלא סקר, אין ממנו גישה לדשבורד |
| דשבורד | `dashboard.html` | מנכ"ל (קוד ראשי, כל התחנות) ומנהלי תחנות (קוד מנהל, רק התחנה שלהם) |
| שמירת נתונים + מיילים | `apps-script/Code.gs` | רץ בתוך Google Sheets בחשבון שלך |

הנתונים נשמרים בגיליון גוגל שלך. הדפים יושבים ב-GitHub Pages.

---

## הקמה (פעם אחת, כ-15 דקות)

### 1. הגיליון וה-Apps Script
1. פותחים גיליון חדש ב-Google Sheets ונותנים לו שם, למשל "משוב חדר אוכל".
2. בתפריט: **הרחבות ← Apps Script**.
3. מוחקים את מה שיש בעורך, ומדביקים את כל התוכן של `apps-script/Code.gs`.
4. בשורה `DASHBOARD_URL` מחליפים לכתובת הדשבורד: `https://<המשתמש>.github.io/<הריפו>/dashboard.html`
5. שומרים, ואז למעלה בוחרים את הפונקציה **setup** ולוחצים **הפעלה (Run)**.
6. גוגל יבקש הרשאות (גיליון, שליחת מיילים, טריגר שעתי) ← מאשרים. אם מופיע "Google hasn't verified this app": ‏Advanced ← Go to … (unsafe). זה הקוד שלך, בחשבון שלך.
7. בגיליון ייווצרו 4 לשוניות: משובים, תחנות, נמענים, הגדרות. תחנת "כוחות זרים - נתב"ג" ו-10 הנמענים כבר בפנים.

### 2. פרסום כ-Web App
1. ב-Apps Script: **Deploy ← New deployment**.
2. Type: **Web app**
3. Execute as: **Me**
4. Who has access: **Anyone**. זה נדרש כדי שהטאבלט יוכל לשלוח בלי להתחבר. הנתונים עצמם מוגנים בקודים, ואף אחד לא יכול לקרוא אותם בלי קוד.
5. **Deploy** ← מעתיקים את ה-**Web app URL** (מסתיים ב-`/exec`).

### 3. GitHub
1. בקובץ `config.js` מדביקים את הכתובת במקום `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE`.
2. מעלים את כל התיקייה לריפו.
3. בריפו: **Settings ← Pages ← Branch: main / root ← Save**.
4. אחרי דקה-שתיים האתר עולה ב-`https://<המשתמש>.github.io/<הריפו>/`

## שימוש

**טאבלט:** פותחים את קישור הטאבלט של התחנה (מעתיקים מהדשבורד ← הגדרות ← "העתקת קישור לטאבלט"), בוחרים תחנה, מזינים את קוד הטאבלט (2 האותיות הראשונות של שם התחנה, לנתב"ג: **כו**). פעם אחת לכל טאבלט.
להחלפת תחנה בטאבלט: לוחצים 3 שניות על שם התחנה בפינה הימנית התחתונה.
מומלץ לנעול את הטאבלט על הדפדפן במסך מלא (באייפד: Guided Access, באנדרואיד: הצמדת מסך).

**דשבורד:** `dashboard.html` ← קוד.
- קוד ראשי ראשוני: **1234**. להחליף מיד בהגדרות.
- תחנה חדשה: הגדרות ← שם + קוד מנהל ← "הוספת תחנה".
- כל מנהל תחנה מקבל קוד מנהל מספרי משלו ורואה רק את התחנה שלו.

**מיילים:** בדשבורד ← "הגדרות שליחת מיילים". לכל נמען: שעה, כתובת ותחנות. הבדיקה רצה כל שעה, ושולחת לכל נמען פעם אחת ביום בשעה שלו. כפתור "מייל ניסיון" שולח עכשיו.
המיילים יוצאים מחשבון הגוגל שלך. בחשבון רגיל המכסה היא 100 נמענים ליום.
